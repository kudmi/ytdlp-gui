YT-DLP Downloader — Cyberpunk Edition  v2.6.3
===============================================

【第一次使用】
1. 需要 Python 3.10 以上（https://www.python.org/downloads/，安裝時勾選 Add python.exe to PATH）。
2. 在程式資料夾開命令提示字元，第一次先建立環境並安裝套件：
     python -m venv .venv
     .venv\Scripts\pip install -r requirements.txt
   之後用這行啟動：
     .venv\Scripts\pythonw YTDL_GUI.pyw
3. 到左側「工具 / 設定」：
   - ffmpeg「下載 / 更新」（合併影音、轉 MP3/FLAC、嵌入封面都需要）
   - Deno「下載 / 更新」（YouTube 需要它才能拿到完整畫質）
   - yt-dlp「更新」（建議 nightly，網站改版時修得最快）
4. 程式打不開或閃退時，改用 .venv\Scripts\python YTDL_GUI.pyw 啟動（python 而不是 pythonw），
   命令提示字元會顯示錯誤訊息；錯誤也會寫到 error.log。

【介面】
左側導覽列：下載 / 下載佇列 / 歷史紀錄 / 執行紀錄 / 帳號・Cookie / 工具・設定
最下方狀態列：即時顯示最新訊息、yt-dlp 通道與程式版本。
關閉視窗預設會縮到工作列系統匣（旁邊的小圖示），不會真的結束程式；在系統匣圖示按右鍵選「結束程式」才會真的關閉。
這個行為可以在「工具 / 設定 › 系統」關掉。

【下載】
- 貼上網址（可一次多行）→ 選模式：影片 + 音訊 / 只要音訊 / 只要影片。
- 影片：畫質、編碼（H.264 相容性最好）、影片格式 mkv / mp4 / webm、影片音質。
- 音訊：MP3 / FLAC / M4A / Opus / WAV / 原始音訊（不轉檔），MP3 可選 320kbps 或 VBR 0。
- 串流清單：按「解析格式」後，ADVANCED「串流清單」會自動展開，用表格列出這支影片所有影片 / 音訊串流
  （解析度、FPS、編碼、HDR、容器、位元率、大小…），可以用「編碼」篩選（例如只看 AV1 / VP9 / H.264）。
  點一列就是指定下載那個串流；第一列「自動」則交給畫質 / 編碼設定。指定串流只套用在解析的那個網址。
- 右側「進行中」面板即時顯示下載進度與接下來的項目。
- 預設檔名格式：上傳日期_標題 [影片ID]。

【B站視頻選集（分 P）】
- 貼上有「視頻選集」的 B站影片網址，按「解析格式」，下方會出現「視頻選集」卡片，列出所有集數。
- 點選要下載的集數，或用「全選 / 全不選 / 反選」，也可以輸入範圍（例如 1-5, 8, 10-）再按「套用範圍」。
- 按「加入佇列」後，每一集會分別加入佇列；下載選項（畫質、格式、音訊⋯）會套用到每一集。
- 選兩集以上時，預設會放進以影片標題命名的資料夾（可取消勾選）。

【下載佇列】
- 上方分頁可篩選：全部 / 下載中 / 等待中 / 完成 / 失敗。
- 失敗的項目會直接顯示錯誤原因與建議，按「重試」即可；完成的項目可「開啟位置」。
- 失敗時預設會自動重試（間隔漸長：10 秒、20 秒、40 秒…，最多重試次數可在「工具 / 設定 › 系統」調整，
  設成 0 等於關閉自動重試）。倒數期間項目仍顯示「失敗」，提示文字會寫重試倒數；想立刻重試可直接按「重試」。
- 整個佇列跑完（不論成功或失敗）會跳出系統通知，告訴你完成與失敗各幾個；可在「工具 / 設定 › 系統」關閉。

【下載歷史】
- 左側導覽「歷史紀錄」：每一筆完成 / 失敗 / 已停止的下載都會留下紀錄（標題、時間、網址、檔案位置），
  重開程式後仍查得到，從「下載佇列」清除的項目也還留在這裡。
- 可用關鍵字搜尋標題 / 網址，也可依「成功 / 失敗 / 已停止」篩選；完成的項目可直接「開啟位置」。
- 「清除紀錄」會清空全部歷史（無法復原），也可以單筆刪除。

【帳號 / Cookie】
- Bilibili：「QR Code 登入」→「產生 QR Code」→ 用 B站 App 掃描。登入後可下載 1080P 以上，大會員可下 4K。
  登入資料存在 cookies\bilibili_login.txt，只在這台電腦。
- YouTube：Google 不允許第三方程式直接用帳號密碼登入，請用：
  a.「瀏覽器」選 Firefox（最穩定），或
  b. 用瀏覽器擴充「Get cookies.txt LOCALLY」匯出 cookies.txt，再選「cookies.txt」。
- B站影片按「解析格式」後，會列出這支影片所有畫質：綠色＝可下載、橘色＝需大會員、紅色＝需登入。
- 其他網站（niconico、Twitch、Instagram…）同樣可用瀏覽器或 cookies.txt。

【多線下載（aria2c）】
YouTube 一般影片、B站影片是單一檔案，yt-dlp 預設只用一條連線下載。開啟多線下載後會改用 aria2c，
同一個檔案最多同時開 16 條連線，頻寬沒跑滿時通常快很多。
1. 「工具 / 設定」→ aria2c 卡片按「下載 / 更新」（約 2.4MB）。
2. 「多線下載」卡片勾選「啟用多線下載」，設定連線數，並選擇要套用的網站。
- 進度改從 aria2c 的控制檔讀取，約每秒更新一次。
- HLS / DASH 分段串流仍用 yt-dlp 內建下載器（由「分段串流並行數」控制）。
- B站最多用 8 條連線（太多會被 CDN 限流、斷線）。
- 某個網站用多線下載出問題時，取消勾選該網站即可回到一般下載。

【系統】
「工具 / 設定 › 系統」：
- 關閉視窗時縮到系統匣（預設開啟）：關閉主視窗只是隱藏，下載會繼續跑；系統匣圖示雙擊可還原視窗，右鍵選單可結束程式。
- 下載完成 / 失敗時顯示系統通知（預設開啟）。
- 啟動時自動檢查 yt-dlp / aria2c 新版（預設開啟）：只是背景查詢 GitHub 最新版號，發現有新版會在「執行紀錄」
  與系統通知提示，不會自動下載或安裝，要更新還是到上方工具卡片按「更新」。
- 失敗自動重試、最多重試次數（0 = 關閉）。

【設定備份】
「工具 / 設定 › 設定備份」：
- 匯出設定：把目前所有設定（含 B站登入 Cookie）打包成一個 .zip，方便備份或搬到另一台電腦。
- 匯入設定：選擇之前匯出的 .zip，會覆蓋目前的設定與 B站登入資料。

【外觀】
「工具 / 設定 › 外觀」可切換 深色 / 淺色 / 跟隨系統，並開關霓虹光暈與背景網格。

【語言 / Language】
「工具 / 設定 › 外觀 › 語言 / Language」可選：跟隨系統（預設）/ 繁體中文 / 简体中文 / English / 日本語。
- 跟隨系統：依 Windows 顯示語言（台灣、香港、澳門 → 繁體中文；中國、新加坡 → 简体中文；日本 → 日本語；其他 → English）。
- 切換後要重新啟動程式才會生效，程式會問要不要立刻重開（下載進行中時會等下次啟動）。
- 翻譯檔在 lang\ 資料夾（zh_CN.json / en.json / ja.json，key = 繁體中文原文）。覺得哪句翻得不好可以直接改，重開程式生效；
  找不到的句子會顯示繁體中文。
- 執行紀錄裡 yt-dlp 本身的訊息一律是英文（yt-dlp 自己的輸出）；這份使用說明只有繁體中文。
下載頁右上角的月亮 / 太陽按鈕可快速切換深淺色。

【打包成單一 exe】
用 PyInstaller 打包，指令見 README.md 的「打包成單一 exe」。會產生 YTDL_GUI.exe（需和 yt-dlp.exe、fonts 資料夾放同一資料夾；
翻譯檔已包進 exe，若同資料夾有 lang\ 資料夾則優先使用它，方便修改翻譯）。

【資料夾內容】
YTDL_GUI.pyw      主程式（介面與下載流程）
ui_theme.py       Cyberpunk 主題：配色、字型、圖示、自繪元件
ytdl_core.py      下載指令、B站登入、工具下載等核心邏輯
i18n.py           多國語言：偵測語言、載入 lang\ 翻譯檔
lang\             翻譯檔（简体中文 / English / 日本語）
app.ico           程式圖示（視窗、工作列、打包的 exe）
fonts\            Orbitron、JetBrains Mono（SIL Open Font License，授權檔同資料夾）
settings.json     設定（自動產生）
history.db        下載歷史紀錄（自動產生，SQLite，可在「歷史紀錄」頁清除）
cookies\          B站登入 Cookie
tools\            ffmpeg / ffprobe / deno / aria2c
cache\            介面用的小圖示（自動產生，可刪）
yt_dlp_plugins\   外掛：原本的 ChromeCookieUnlock、新增的 BiliCDNFix（B站 CDN 節點修正）
